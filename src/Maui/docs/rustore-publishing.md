# Публикация «Конь на доске» в RuStore

Пошаговая инструкция: собрать подписанный APK из PowerShell и выгрузить его в RuStore Консоль.

Источники — справка RuStore (проверена на момент написания; интерфейс и требования магазина могут меняться, поэтому сверяйтесь со справкой):

- [Публикация приложения](https://www.rustore.ru/help/en/developers/publishing-and-verifying-apps/app-publication)
- [Подпись APK и AAB](https://www.rustore.ru/help/en/developers/publishing-and-verifying-apps/app-publication/apk-signature)
- [Загрузка новой версии](https://www.rustore.ru/help/en/developers/publishing-and-verifying-apps/app-publication/new-version-app)

Пункты, которых нет в справке или которые зависят от вашей консоли, помечены **«уточнить»** — здесь они не выдуманы.

## 0. Что нужно заранее

- Аккаунт разработчика RuStore. Он у вас уже есть (приложение «Музей Юмора»). Новое приложение добавляет **владелец аккаунта** (Account Owner); загружать версии могут также администратор, релиз-менеджер и разработчик.
- Windows 11, .NET 10 SDK с нагрузкой `maui-android`, JDK (ставится вместе с нагрузкой MAUI в Visual Studio). Подготовка проекта — `README.md`, выполнен `setup.ps1`.
- Тесты ядра зелёные.

Параметры приложения в `src/Calabonga.HorseOnTheGrid.Mobile/Calabonga.HorseOnTheGrid.Mobile.csproj`:

| Свойство | Значение | Заметка |
|---|---|---|
| `ApplicationId` | `net.calabonga.horseonthegrid` | package name; уникален и после первой публикации не меняется |
| `ApplicationDisplayVersion` | `1.0` | версия для людей |
| `ApplicationVersion` | `1` | номер сборки; для каждой следующей версии в RuStore должен быть **больше** предыдущей |
| `ApplicationTitle` | «Конь на доске» | название под иконкой |

## 1. Создание сертификата (хранилища ключей)

Один раз на приложение. Подпись должна оставаться **одной и той же** во всех следующих версиях: RuStore требует, чтобы подпись новой версии совпадала с предыдущей.

> Хранилище ключей **не кладите в репозиторий** (`*.keystore` в `.gitignore`) и сделайте его резервную копию в надёжное место. Потеря ключа или пароля означает невозможность обновлять приложение: смена ключа в RuStore возможна только через письмо в support@rustore.ru.

Утилита `keytool` входит в JDK. Если её нет в `PATH`, найдите: `Get-ChildItem 'C:\Program Files\Microsoft\jdk*','C:\Program Files\Android' -Recurse -Filter keytool.exe -ErrorAction SilentlyContinue` (путь зависит от установки — **уточнить** на своей машине).

```powershell
New-Item -ItemType Directory -Force C:\Keys | Out-Null

keytool -genkeypair -v `
    -keystore C:\Keys\horse.keystore `
    -alias horse `
    -keyalg RSA -keysize 2048 `
    -validity 10000
```

`keytool` спросит пароль хранилища, имя, организацию и т. д. Запишите пароль и alias (`horse`) в менеджер паролей. Параметры (`RSA 2048`, срок 10000 дней) — обычная практика для Android; требований RuStore к алгоритму и сроку в справке нет.

Проверка и отпечатки (пригодятся, если понадобится сверить подпись с другим магазином):

```powershell
keytool -list -v -keystore C:\Keys\horse.keystore -alias horse
```

**Вопрос про другие магазины.** Если «Конь на доске» уже опубликован или будет опубликован в Google Play или другом магазине, подпись в RuStore должна совпадать с ней (иначе пользователи не смогут обновляться между магазинами). Если приложение только в RuStore, подходит новый ключ.

## 2. Сборка и подпись из PowerShell

Пароль не пишите в команду — передайте через переменную окружения текущего сеанса:

```powershell
cd <путь к>\src\Maui

# 1. Тесты
dotnet test .\tests\Calabonga.HorseOnTheGrid.Core.Tests

# 2. Пароль (ввод скрытый); и для хранилища, и для ключа используется один пароль
$env:HORSE_KEY_PASS = Read-Host "Пароль хранилища ключей"

# 3. Сборка подписанного APK
dotnet publish .\src\Calabonga.HorseOnTheGrid.Mobile `
    -f net10.0-android -c Release `
    -p:AndroidPackageFormats=apk `
    -p:AndroidKeyStore=true `
    -p:AndroidSigningKeyStore=C:\Keys\horse.keystore `
    -p:AndroidSigningKeyAlias=horse `
    -p:AndroidSigningKeyPass=env:HORSE_KEY_PASS `
    -p:AndroidSigningStorePass=env:HORSE_KEY_PASS

# 4. Убрать пароль из сеанса
Remove-Item Env:\HORSE_KEY_PASS
```

Готовый файл — в `src\Calabonga.HorseOnTheGrid.Mobile\bin\Release\net10.0-android\publish\`, с суффиксом `-Signed.apk` (например, `net.calabonga.horseonthegrid-Signed.apk`). Именно его загружайте в RuStore.

Формат AAB (`-p:AndroidPackageFormats=aab`) RuStore тоже принимает, но для него подпись приложения нужно отдельно загрузить в консоль до загрузки файла (см. справку «Upload AAB»). Для первой публикации проще APK.

### Проверка подписи перед загрузкой

`apksigner` входит в Android SDK (Build Tools). Путь и версия зависят от установки — **уточнить**:

```powershell
& "$env:ANDROID_HOME\build-tools\<версия>\apksigner.bat" verify --print-certs `
    .\src\Calabonga.HorseOnTheGrid.Mobile\bin\Release\net10.0-android\publish\net.calabonga.horseonthegrid-Signed.apk
```

## 3. Выгрузка в RuStore Консоль

1. Войдите в RuStore Консоль, откройте вкладку **«Приложения»** → **«Добавить приложение»**, введите название (до 30 символов, уникальное) → **«Добавить»**.
2. Выберите приложение → **«Загрузить новую версию»**.
3. Тип приложения: **Universal** (телефон, планшет, ТВ) или **TV Only**. Игра рассчитана на телефон в портретной ориентации; для Universal справка требует ещё и данные для ТВ — **уточнить**, нужен ли здесь вариант Universal (для «Музея Юмора» вы, вероятно, уже выбирали).
4. Загрузите `...-Signed.apk`. Требования первой версии: размер до 5 ГБ, подпись сертификатом, уникальный package name. Оставайтесь на странице до конца загрузки; после этого идёт обработка (в это время черновик можно сохранить и уйти). Обработанный файл хранится 14 дней, потом удаляется, если версию не отправили на модерацию.
5. Заполните **«Что нового»** (для первой версии — краткое описание релиза).
6. **User data safety** — декларация данных и чувствительных разрешений. Из кода видно, что игра хранит только локальный рекорд (`Preferences`); какие разрешения попадут в итоговый APK, зависит от `AndroidManifest.xml` из шаблона (создаётся `setup.ps1`) — проверьте его и отвечайте по тому, что покажет консоль, — **уточнить**.
7. **Информация о приложении:**
   - название (до 30 символов);
   - категория (для игры — также метки игрового контента);
   - возрастное ограничение — как выбрать, описано на отдельной странице справки, **уточнить**;
   - поисковые теги (до 5, необязательно);
   - краткое описание (до 80 символов);
   - полное описание (до 4000 символов; ключевое — в первые 2000);
   - минимальная версия Android подтягивается из манифеста автоматически.
8. **Контакты разработчика:** нужен хотя бы один — email, группа ВК или сайт. Для новых версий контакты подставляются из предыдущей версии того же приложения.
9. **Медиафайлы:**
   - иконка **512×512**, `.png` или `.jpg`, до 3 МБ, фон заполняет всю область (без прозрачности);
   - скриншоты для телефона — обязательно, **не менее 3**, `.png`/`.jpg`, до 3 МБ каждый, максимум 2160×3840, рекомендуемое соотношение 16:9; готовые снимки экрана лежат в `docs/screenshots/` (`start.png`, `first-move.png`, `dead-end.png`) — проверьте их размеры и вес;
   - скриншоты для планшета — необязательно; видео — необязательно (только ссылка на VK Видео).
10. FAQ — необязательно (до 10 пар вопрос-ответ).
11. Перед отправкой сверьтесь с требованиями RuStore к приложениям (App Review Guidelines), затем нажмите **«Отправить на модерацию»** (либо сохраните черновик; черновик у приложения может быть только один).
12. Политика конфиденциальности: поле в справке по загрузке не описано — **уточнить**, запрашивает ли его консоль и нужен ли URL.

Срок модерации в справке не указан.

## 4. Какие файлы куда загружаются

| Файл | Откуда | Куда |
|---|---|---|
| `net.calabonga.horseonthegrid-Signed.apk` | `src\Calabonga.HorseOnTheGrid.Mobile\bin\Release\net10.0-android\publish\` | форма «Загрузить новую версию» → файл приложения |
| иконка 512×512 | подготовить отдельно (в проекте только `appicon.svg` для иконки приложения) | «Медиафайлы» → иконка |
| не менее 3 скриншотов телефона | `docs/screenshots/*.png` или новые снимки | «Медиафайлы» → скриншоты (телефон) |
| `horse.keystore` | `C:\Keys\` | **никуда не загружается**; хранить в секрете, делать резервную копию |

## 5. Следующие версии

1. Увеличьте `ApplicationVersion` (и при желании `ApplicationDisplayVersion`) в `.csproj`.
2. Соберите APK тем же хранилищем и alias.
3. В консоли: приложение → **«Загрузить новую версию»**. Подпись и package name должны совпадать с предыдущей версией, номер версии — быть выше.
