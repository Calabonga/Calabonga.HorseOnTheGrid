# Spec Delta

## Purpose

Определяет геометрию хода шахматного коня на квадратном поле 10×10 и способ, которым клетки нумеруются для игрока.

## ADDED Requirements

### Requirement: Ход буквой «Г»
Приложение SHALL считать ходом коня перемещение на две клетки в одном направлении и на одну в перпендикулярном (всего восемь смещений); любое другое перемещение — не ход коня.

#### Scenario: Допустимое смещение
- **WHEN** конь стоит в клетке x:1, y:1 и игрок выбирает клетку x:2, y:3
- **THEN** перемещение считается ходом коня

#### Scenario: Недопустимое смещение
- **WHEN** игрок выбирает клетку, которая смещена на одну клетку по диагонали, по прямой или на две клетки по обеим осям
- **THEN** перемещение не считается ходом коня

### Requirement: Ходы только в пределах поля
Приложение SHALL предлагать и принимать ходы только на клетки внутри поля 10×10.

#### Scenario: Угловая клетка
- **WHEN** конь стоит в углу поля
- **THEN** из этой клетки возможны ровно два хода

#### Scenario: Центральная клетка
- **WHEN** конь стоит в центре поля, вдали от краёв
- **THEN** из этой клетки возможны ровно восемь ходов

### Requirement: Нумерация клеток для игрока
Приложение SHALL показывать и называть клетки с номеров от 1: столбцы слева направо, строки сверху вниз; левая верхняя клетка — x:1, y:1.

#### Scenario: Название левой верхней клетки
- **WHEN** приложению нужно назвать левую верхнюю клетку (например, в журнале)
- **THEN** она называется «x:1, y:1»
